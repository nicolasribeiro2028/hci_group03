# Interviews

Interview reports for the project. Fill in [_template.md](_template.md) within an hour of each interview, while it's fresh.

Naming: copy the template to `YYYY-MM-DD_participant-code.md` (e.g. `2026-10-05_P01.md`).

Tips:
- Keep question 6 (quotes) and question 10 (how the interview went) short but specific. Quotes feed the write-up; question 10 helps refine the outline between interviews.
- Use a participant code or initials, not full names.

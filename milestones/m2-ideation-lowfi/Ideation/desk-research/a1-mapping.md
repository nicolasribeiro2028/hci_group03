# Mapping to Report Section A.1

How the helper files feed [../ideation-report.md](../ideation-report.md).

| Report part | Built from | Notes |
|---|---|---|
| Related work table (10+ sources) | [sources.md](sources.md) | Add one key insight per source from [by-need.md](by-need.md). Keep cells short |
| Baseline feature comparison | [baselines.md](baselines.md) | Limit to 3 or 4 baselines to fit the page |
| Most related solution paragraph | [baselines.md](baselines.md) | One short paragraph with an image if possible |
| Insights for the affinity diagram (A.3) | [by-need.md](by-need.md) | Each insight becomes one note, tagged with its need |

## Suggested order in the report

1. One sentence on how the desk research was done, organized by the five needs.
2. Source table, grouped by need.
3. Baseline comparison table.
4. Most related solution paragraph.

# Formative Testing

Formative testing collects feedback on the lo-fi prototypes from users and checks whether their needs are met. The output is one PDF, **Formative Testing Report**, written in [formative-testing-report.md](formative-testing-report.md).

## Task

1. Peer testing
   - Define the tasks used for peer feedback.
   - Test each prototype with two people outside the group. Each of the two people tests both prototypes.
   - Ask peers to think aloud. Take observational notes (confusion, delight, hesitation, unexpected behavior).
2. Heuristic evaluation
   - Inspect both prototypes with five of Nielsen's usability heuristics, choosing the five most relevant to the design.
   - Done by us as experts. We choose how many group members take part.
   - Record observations in the Heuristic Evaluation Workbook.
   - Identify where the design meets or violates each heuristic, summarize the findings and note the design changes for critical issues.

## Report sections

- **C.0 Declaration of Use of AI:** short declaration of which AI tools were used and how. If none were used, say so explicitly.
- **C.1 Peer Testing:**
  - Participants, including group numbers of peers from other groups.
  - Tasks, each briefly explained.
  - Peer feedback summary (1000 to 2000 characters) for both prototypes.
  - Observations: how participants interacted, where behavior matched or diverged from the intended design, unexpected reactions.
  - Comparison and reflection: what worked, what did not and why, which features to keep, improve or discard.
  - Conclusion: which prototype or idea seems most promising.
- **C.2 Heuristic Evaluation:**
  - Consolidate individual workbooks into one file per prototype.
  - Usability issues summary per prototype, each tied to a heuristic.
  - Reflection: how the results align with or differ from peer testing, and which issues emerged only through inspection.

## Submission

- One PDF named "Formative Testing Report" (here: `g3-formative-testing-report.pdf`).
- Consolidated workbooks in `Deliverables/FormativeTesting/HeuristicEvalutaion/Workbook_IdeaA/` and `Workbook_IdeaB/`.

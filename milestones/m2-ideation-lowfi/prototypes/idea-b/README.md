# Idea B prototype

Working folder for the Idea B lo-fi prototype. The design to mimic is the **Lo-fi** page in the Figma file [HCI Group B](https://www.figma.com/design/0rPJ2At16HVd3B5wUfCgDa/HCI-Group-B?node-id=33-5).

Build the interactive prototype here. The report text stays in [LoFiPrototyping/lofi-prototyping-report.md](../../LoFiPrototyping/lofi-prototyping-report.md).

## Screen to copy

The screen to copy is the workspace labeled `idea-b-workspace9`, not the earlier wireframes on the same page. It is a 1512 by 982 desktop layout with a header and three columns.

## Layout

- Header: course context dropdown, **+ Add context**, and **Profile**.
- Left column: course material, file upload, and topics found with a **Rate my knowledge** link and 0 to 10 ratings.
- Middle column: open lecture slides, with one tab per file.
- Right column: chat, with a chat switcher, **+ New chat**, scripted answers, a confidence label, and a composer.

## States already drawn

- Profile setup: "Hey, ready to study?", a short bio, and prior math courses.
- Empty workspace before any files are added.
- Files added, lecture open, topics listed as not rated.
- Chat answers that are either missing from the material or grounded in a slide, each with a confidence label.
- Practice flow in the chat, including step-by-step help.
- **Add a course context** dialog.
